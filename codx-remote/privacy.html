Política de Privacidade — Codx Remote

Última atualização: 4 de outubro de 2026.

O Codx Remote conecta dispositivos autorizados pelo usuário a clientes MCP, como o ChatGPT. O serviço foi projetado para executar somente ações solicitadas por uma sessão autenticada e por um dispositivo que o próprio usuário conectou.

Dados processados

Podemos processar identificadores de conta e dispositivo, nome do computador, status online, contadores de uso, solicitações de ferramentas MCP, caminhos de arquivos, conteúdo necessário para executar a ferramenta solicitada e saídas de comandos. Credenciais de conta são armazenadas como hashes de senha; tokens e estado persistente do relay são protegidos no backend.

Conteúdo do computador

O Codx Remote não varre o computador em segundo plano. Arquivos e comandos são acessados apenas quando uma ferramenta é chamada. Payloads e resultados do relay são usados para entregar a chamada e são removidos após a conclusão quando possível.

Compartilhamento

Não vendemos dados pessoais. Dados são enviados apenas aos serviços necessários para operar o Codx Remote e ao cliente MCP que o usuário autorizou.

Controle do usuário

O usuário pode encerrar o agente com Ctrl+C, revogar dispositivos no Manager e alterar suas credenciais. Fechar o agente deixa o computador offline.

Segurança

O transporte público usa HTTPS. O relay usa autenticação por dispositivo e OAuth para clientes MCP. O usuário não deve compartilhar URLs privadas, tokens ou credenciais.

Contato

Use o site do projeto ou o repositório público do Codx Remote para relatar problemas de segurança ou privacidade.
