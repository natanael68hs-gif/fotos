COMO FUNCIONA

Seu PC continua privado

O agente roda localmente. O túnel sai do seu PC por HTTPS até a OpenAI, então não é necessário abrir porta no roteador.

01

Instale

Rode um único comando no PowerShell. O instalador prepara Node.js, Desktop Commander e o cliente de túnel.

02

Conecte

Na primeira execução, informe seu Tunnel ID e a chave de runtime da OpenAI. A chave fica protegida localmente pelo Windows.

03

Use no chat

Adicione o túnel como app MCP no ChatGPT. Com o terminal aberto, o chat consegue usar as ferramentas do PC.

INSTALL

Um comando no PowerShell

Abra o PowerShell normal e cole:

irm https://codx-remote-zrider.vercel.app/install.ps1 | iex
Na primeira vez: o instalador pede o Tunnel ID e uma Runtime API key. Depois disso, o mesmo comando apenas inicia o Codx Remote.

SEGURANÇA

Feito para controle explícito

✓ Sem serviço oculto ou inicialização automática.
✓ Fechou o PowerShell ou Ctrl+C: fica offline.
✓ Nenhuma porta de entrada precisa ficar aberta.
✓ Runtime key armazenada criptografada pelo Windows.
✓ Engine local baseada no Desktop Commander open-source.
✓ Painel administrativo local em 127.0.0.1.
IMPORTANTE

Conta do ChatGPT e uso

O site não recebe sua senha nem faz “Login com ChatGPT”. A ligação com a sua conta acontece dentro do próprio ChatGPT quando você adiciona o MCP/Tunnel. O site apenas instala e orienta o cliente local.
