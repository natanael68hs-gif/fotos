COMO FUNCIONA

Seu PC continua privado

O agente roda localmente e consulta o relay Codx Remote por HTTPS. Não é necessário abrir porta no roteador.

01

Instale

Rode um único comando no PowerShell. O instalador prepara Node.js e baixa o agente próprio do Codx Remote.

02

Conecte

Na primeira execução, o PC é registrado automaticamente e recebe suas URLs privadas de MCP e Manager.

03

Use no chat

Adicione a URL MCP mostrada no terminal ao ChatGPT. Com o terminal aberto, o chat consegue usar as ferramentas do PC.

SEGURANÇA

Feito para controle explícito

✓ Sem serviço oculto ou inicialização automática.
✓ Fechou o PowerShell ou Ctrl+C: fica offline.
✓ Nenhuma porta de entrada precisa ficar aberta.
✓ Estado do relay armazenado criptografado no backend.
✓ Agente Windows próprio, sem depender do Desktop Commander.
✓ Manager privado com status e revogação de dispositivos.
IMPORTANTE

Conta do ChatGPT e uso

O site não recebe sua senha do ChatGPT. O agente cria uma URL MCP privada; essa URL é o que você conecta ao ChatGPT. Não compartilhe a URL MCP nem o link do Manager.
