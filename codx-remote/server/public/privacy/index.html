POLÍTICA DE PRIVACIDADE

Privacidade no Codx Remote.

Esta política explica quais dados o Codx Remote processa para conectar computadores autorizados, executar ferramentas remotas, proteger contas e operar o serviço.

1. Dados que processamos

Dados de conta: nome, endereço de e-mail, senha armazenada somente em formato derivado/hasheado, sessões de login e identificadores técnicos necessários para autenticação.

Dados de dispositivos: nome e identificador do computador, estado online/offline, último sinal recebido, estado de revogação e contadores de uso.

Dados de conexão: identificadores de clientes MCP/OAuth, escopos autorizados, sessões e tokens necessários para manter conexões autorizadas. Segredos e tokens são tratados como credenciais e não devem ser compartilhados publicamente.

Solicitações remotas: argumentos enviados para ferramentas, como caminhos de arquivos ou comandos, e os resultados necessários para responder à solicitação. Esses dados podem transitar pelo backend durante a execução.

Metadados operacionais: nome da ferramenta utilizada, status, duração e horário, além de logs técnicos necessários para segurança, disponibilidade e diagnóstico.

2. Como usamos esses dados

Usamos os dados somente para autenticar usuários, vincular computadores autorizados, encaminhar solicitações às máquinas corretas, retornar resultados, exibir status no dashboard, aplicar limites de uso, detectar falhas e proteger o serviço contra abuso.

O Codx Remote não vende dados pessoais e não usa conteúdo de arquivos ou comandos para publicidade.

3. Compartilhamento

Os dados podem ser processados por provedores de infraestrutura necessários para hospedar o serviço e o banco de dados. Dados também são enviados ao cliente MCP escolhido pelo usuário quando isso é necessário para responder à solicitação iniciada por ele.

Não compartilhamos dados pessoais com anunciantes nem com terceiros para fins de marketing.

4. Retenção

Dados de conta e dispositivos são mantidos enquanto a conta ou o vínculo do dispositivo permanecer ativo, salvo quando uma obrigação técnica ou legal exigir retenção adicional.

Sessões de login expiram automaticamente. Tokens OAuth possuem prazo de expiração e podem ser revogados. Metadados de atividade podem ser mantidos por até 30 dias.

Comandos e resultados são mantidos apenas pelo tempo necessário para concluir a operação, entregar a resposta ou encerrar uma execução por falha/timeout, após o que são removidos do fluxo operacional.

Logs de infraestrutura podem ter retenção própria definida pelo provedor de hospedagem para operação, segurança e diagnóstico.

5. Controle do usuário

No dashboard, você pode desconectar ou revogar dispositivos, revogar conexões OAuth e trocar credenciais de acesso. Encerrar o agente interrompe a comunicação daquele computador.

Para solicitar acesso, correção ou exclusão dos dados da conta, use a página de Suporte. Não envie senhas, tokens ou arquivos pessoais em chamados públicos.

6. Segurança

O serviço usa HTTPS, credenciais de acesso, tokens de sessão e validações de autorização para limitar operações aos dispositivos e contas correspondentes. Nenhum sistema é totalmente livre de riscos; mantenha suas credenciais privadas e revogue acessos que não reconheça.

7. Crianças

O Codx Remote não é direcionado a crianças menores de 13 anos e não foi projetado para coletar conscientemente dados pessoais de crianças.

8. Alterações desta política

Podemos atualizar esta política quando o serviço ou suas práticas mudarem. A versão publicada nesta página é a versão vigente.

9. Contato

Para dúvidas de privacidade, exclusão de dados ou suporte, acesse https://codx-remote.onrender.com/support.
