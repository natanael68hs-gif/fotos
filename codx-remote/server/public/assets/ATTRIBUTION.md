# Brand assets

- `codx-symbol.png` and `codx-wordmark.png`: supplied by the project owner. Original transparency and proportions preserved.
- `chatgpt.svg`: OpenAI Blossom, obtained from the Simple Icons 15.0.0 asset collection (`https://github.com/simple-icons/simple-icons/blob/15.0.0/icons/openai.svg`). Used only to identify the OpenAI integration. OpenAI brand guidelines: `https://openai.com/brand/`.
- `claude.svg`: Claude mark from Simple Icons (`https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg`), used to identify the integration currently under maintenance.
- `codex.png`: unmodified transparent app icon from the installed official OpenAI Codex Windows package (26.930.3930.0). Used only to identify the Codex integration.

Product names and marks belong to their respective owners. Codx Remote is an independent project.
